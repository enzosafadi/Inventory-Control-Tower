## Milestone acceptance standards

- **Concept:** Explicit business use case, users, value hypothesis and constraints recorded.
- **Requirements:** Versioned scope, acceptance criteria, stakeholder/owner approval.
- **Prototype:** Reproducible working demo, synthetic/test data and documented limitations.
- **Integration / data:** Validated interfaces, data contracts, error handling and security boundaries.
- **Quality and security:** Current CI passing, manual end-to-end tests, threat model, IP/security review.
- **Production readiness:** Hardened configuration, deployment, access control, monitoring and rollback.
- **Buyer outreach:** Approved contact list, tested pitch, evidence of real buyer conversations and demonstration.
- **Commercial sale:** Signed buyer acceptance and paid contract.
