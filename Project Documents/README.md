# Project Documents

This folder is the controlled documentation home for prospective commercial customization. Six versioned PDF records are required:

1. Requirements - client specifications across business, functional, nonfunctional, data, AI-specific and acceptance criteria.
2. Validation - ambiguities, conflicts, missing information and technical constraints.
3. Approval - the approved requirements baseline.
4. Development - traceability to implemented functionality.
5. Testing - evidence against acceptance criteria.
6. Change Control - modifications and new versions.

Owner-provided specifications take precedence over inferred requirements. Questions are bold, answers italic. Every PDF carries a version and approval status. Never invent client answers or approvals. Preserve earlier versions. All records start as internal drafts until a client responds.
